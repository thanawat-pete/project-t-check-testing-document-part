# **SPRS-Test-Cases — แผนการทดสอบและชุดกรณีทดสอบระบบจัดการเอกสาร (Document Management Test Suite)**

**โครงการ:** T-check (ระบบตรวจสอบและจัดการเอกสารภาษาไทยอัจฉริยะ)  
**โมดูล:** ระบบการจัดการเอกสาร (Document Management Subsystem)  
**เป้าหมายการทดสอบ:** Web Application (https\://t-check-two.vercel.app) & Backend REST API (tcheck-backend-real)  
**เวอร์ชันเอกสาร:** 3.1.0 (Production & CI/CD Synchronized)  
**วันที่จัดทำ:** 2026-08-18

## ---

**1\. ข้อมูลภาพรวมการทดสอบ (Test Plan & Scope Overview)**

### **1.1 วัตถุประสงค์ (Test Objectives)**

ชุดกรณีทดสอบนี้จัดทำขึ้นเพื่อตรวจสอบความถูกต้อง สมบูรณ์ ความปลอดภัย และประสิทธิภาพของ **"ระบบการจัดการเอกสาร (Document Management Subsystem)"** ของระบบ T-check ตามโค้ดจริง ทั้งในระดับ E2E Web UI Testing, Functional Workflow, State Persistence, Data Isolation (Multi-Tenancy / IDOR), และ Boundary Testing

### **1.2 สภาพแวดล้อมและข้อมูลทดสอบ (Test Environment & Preconditions)**

> * **Frontend Target URL:** https\://t-check-two.vercel.app (Vite \+ React)  
> * **Backend API & Mock Mechanism:** REST API / Deterministic Mock Route via auth.helper.ts  
> * **Authentication Mechanism:** Zustand Persist Store ใน localStorage (auth-storage) และ Session Storage  
> * **Playwright Configuration:** baseURL, slowMo: 800ms, video, screenshot, trace, timeout: 60000ms  
> * **CI/CD & Deployment:** Runner: ubuntu-latest, Browser: Chromium Headless  
> * **บัญชีทดสอบที่กำหนดล่วงหน้า (Predefined Test Personas):** Guest, User-A (Free), User-B (Free), User-C (Pro), Admin

## **4\. วิธีการรันชุดการทดสอบ Playwright (How to Run Playwright Tests)**

### **4.1 คำสั่งสำหรับรันภายในเครื่อง (Local Execution)**

`# 1. ติดตั้ง Dependencies และ Playwright Browsers`  
`npm install`  
`npx playwright install chromium`

`# 2. รันชุดทดสอบทั้งหมดในโหมด Headless (พร้อมบันทึก Video และ HTML Report)`  
`npm test`  
`# หรือ`  
`npx playwright test`

`# 3. รันชุดทดสอบแบบเปิดหน้าต่างเบราว์เซอร์ให้เห็นการทำงานแบบ Slow-Motion (Headed)`  
`npm run test:headed`

`# 4. รันผ่าน Playwright UI Mode แบบโต้ตอบ (Interactive)`  
`npm run test:ui`

`# 5. เปิดดูรายงานผลการทดสอบ HTML Report ล่าสุด`  
`npm run test:report`

### **4.2 ระบบการทดสอบอัตโนมัติบน CI/CD (GitHub Actions Pipeline)**

ระบบได้ตั้งค่า **GitHub Actions Workflow** ไว้ที่ .github/workflows/playwright.yml โดยทำงานอัตโนมัติดังนี้:

> 1. **Trigger อัตโนมัติ:** เมื่อมีการ push หรือสร้าง pull\_request ไปยัง Branch main / master รวมถึงรองรับ workflow\_dispatch  
> 2. **สภาพแวดล้อม CI:** รันบน ubuntu-latest ด้วย Node.js LTS พร้อมติดตั้ง Chromium และระบบ Dependencies ครบถ้วน  
> 3. **Artifact Backup:** บันทึกไฟล์ .zip รายงานผลและคลิปวิดีโอการทดสอบเก็บไว้ใน GitHub Actions Artifacts เป็นเวลา 30 วัน  
> 4. **Auto-Deploy GitHub Pages:** อัปเดตและเผยแพร่หน้า HTML Report ขึ้น GitHub Pages โดยอัตโนมัติทุกครั้งที่รันเสร็จ
